# MindTrack

Справочник скрининговых психологических тестов: PHQ-9, GAD-7, MDQ, ASRS, PSS-10, ISI, WHO-5.

- Без регистрации и серверов — всё работает в браузере.
- Результаты хранятся только в вашем браузере (localStorage).
- Результат можно скопировать текстом или скачать как `.txt` — удобно отправить врачу.

> ⚠️ **Важно:** MindTrack **не является медицинским ПО** и не ставит диагнозы. Это инструмент самонаблюдения. При тревожных симптомах обращайтесь к профессионалам.
>
> В непосредственной опасности звоните **112**. **8-800-2000-122** — детский телефон доверия для детей, подростков и родителей; это не универсальная взрослая кризисная линия.

## Функции

- 📊 Прохождение 7 скрининговых опросников: PHQ-9, GAD-7, MDQ, ASRS, PSS-10, ISI, WHO-5.
- 📝 История результатов локально в браузере (без аккаунта).
- 📋 Экспорт результата текстом, печать отчёта и JSON-бэкап истории.
- 🔗 Отдельные URL для каталога, описания теста, прохождения, результатов и справочных страниц.
- ⏯️ Локальное продолжение незавершённого прохождения.
- 🆘 Кризисный баннер с 112, детской линией доверия и региональной службой Москвы; ресурсы подписаны по региону и возрасту.
- 🌗 Тёмная/светлая тема, адаптивный интерфейс.

## Технологии

- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn/ui, Zustand.
- **Бэкенда нет:** подсчёт баллов и хранение — полностью на клиенте (`src/data/tests.ts`, `src/lib/results.ts`).

## Быстрый старт

### Требования

- [Bun](https://bun.sh/) 1.3.14 (версия закреплена в `.bun-version`)

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Simifar/mindtrack.git
cd mindtrack

# 2. Установить зависимости
bun install --frozen-lockfile

# 3. Запустить dev-сервер
bun run dev
```

Откройте `http://localhost:3000`.

## Тесты

| Код | Название | Вопросов | Режим |
|-----|----------|----------|-------|
| PHQ9 | Шкала депрессии | 9 | сумма 0–27 |
| GAD7 | Шкала тревожности | 7 | сумма 0–21 |
| MDQ | Скрининг биполярного спектра | 13 + 2 условия | 7+ симптомов, совпадение по времени и влияние |
| ASRS | Скрининг СДВГ у взрослых | 6 | отдельные пороги, 4+ критерия |
| PSS10 | Шкала воспринимаемого стресса | 10 | сумма 0–40 |
| ISI | Индекс тяжести бессонницы | 7 | сумма 0–28 |
| WHO5 | Индекс благополучия | 5 | сумма 0–25 и 0–100 |

Тесты и скоринг: `src/data/tests.ts`. Юнит-тесты: `bun test`.

Для browser smoke-тестов в отдельном терминале запустите `bun run dev`, затем выполните `bun run test:e2e`.

## Архитектура

- **Клиентский интерфейс:** интерактивные экраны работают на клиенте, URL является источником состояния маршрута.
- **URL-маршруты:** `/tests`, `/tests/<slug>`, `/tests/<slug>/run`, `/results`, `/diary`, `/visit`, `/about`, `/help`, `/privacy`.
- **Статика:** проекта собирается в обычный Next.js-билд, сервера и БД не нужно.

## Методики и ограничения

В приложении отображаются источники, версия периода вопросов, сведения о русской формулировке и лицензировании каждой шкалы. Официальность русских переводов не заявляется без отдельного подтверждения правообладателя.

MDQ использует 13 симптомов и два дополнительных условия. ASRS-v1.1 использует отдельные пороги для первых и последних пунктов. PSS-10 обратно кодирует пункты 4, 5, 7 и 8. ISI использует разные варианты ответа для симптомов, удовлетворённости, заметности, беспокойства и влияния на дневную жизнь.

Результаты — самонаблюдение, а не диагноз или оценка непосредственного риска. При сохраняющихся или ухудшающихся симптомах обратитесь к специалисту.

## Деплой

Проект собирается в статический экспорт (`out/`) и не требует Node.js-сервера Next.js. Для локального предпросмотра:

```bash
bun run build
bun start
```

Для GitHub Pages workflow задаёт `PAGES_BASE_PATH` автоматически. На другом project-site его можно задать перед сборкой, например `PAGES_BASE_PATH=/mindtrack bun run build`.
