# Roadmap

1. Проверить переводы и источники каждой шкалы; заполнить `sourceUrl` только
   подтверждёнными безопасными ссылками.
2. Добавить редакционные карточки о границах применения, версиях и датах
   проверки без выдумывания фактов.
3. Подключить ручную проверку внешних ссылок отдельным workflow.
4. После редакционного приёмочного теста включить GitHub Pages для репозитория.
