# Contributing to MindTrack

Спасибо, что хотите участвовать в развитии проекта! Пожалуйста, придерживайтесь следующих простых правил.

## Как внести вклад

1. Создайте [Issue](https://github.com/username/mindtrack/issues), чтобы обсудить изменение, если оно крупное.
2. Форкните репозиторий и создайте ветку:
   ```bash
   git checkout -b feature/краткое-описание
   ```
3. Внесите изменения. Следите за тем, чтобы:
   - код проходил `bun run lint`;
   - миграции Prisma были осмысленными;
   - не коммитились секреты (`.env`, ключи).
4. Напишите понятное описание Pull Request.

## Рекомендации

- **Безопасность превыше всего:** любое изменение, касающееся аутентификации, шифрования или персональных данных, требует особого внимания.
- **Не медицинское ПО:** не добавляйте функции, которые могут быть истолкованы как диагностика или медицинская рекомендация.
- **Локализация:** основной язык интерфейса — русский, код и коммиты — на русском или английском.
- **Минимальные зависимости:** избегайте добавления тяжёлых библиотек без явной необходимости.
