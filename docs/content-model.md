# Модель контента

Контент MindTrack хранится в типизированных коллекциях `src/data/topics.ts` и
`src/data/scales.ts`. Каждая запись имеет стабильные `id` и URL-safe `slug`.
Связи между шкалами и разделами задаются через `topicIds`, а не через названия.

`reviewStatus` принимает `assessed`, `pending` или `unassessed`. Непроверенные
сведения не выдаются за рекомендации. Внешние ссылки могут быть `null`; при
добавлении ссылки валидатор разрешает только `http` и `https` без credentials.

Перед публикацией запускается `bun run validate-content`: он проверяет схему
записей, уникальность идентификаторов и существование связанных разделов.
