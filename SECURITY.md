# Security Policy

MindTrack — статическое клиентское приложение. Ответы и результаты хранятся только в localStorage браузера пользователя; аккаунтов, серверного API и базы данных в проекте нет.

## Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| 0.3.x  | ✅ Актуальная |
| < 0.2  | ❌ Не поддерживается |

## Как сообщить об уязвимости

Пожалуйста, **не создавайте public Issue** для уязвимостей, связанных с безопасностью.

Вместо этого:

1. Отправьте описание на email проекта (или через личные сообщения мейнтейнера).
2. Укажите шаги для воспроизведения, возможное влияние и, если есть, варианты исправления.
3. Дайте нам разумное время для исправления до публичного раскрытия.

## Меры безопасности в проекте

- Серверного хранения ответов и результатов нет.
- Регистрации, аккаунтов, cookie-сессий и базы данных нет.
- Кризисные ответы обрабатываются локально, без автоуведомлений третьих лиц.
- История может быть удалена пользователем из интерфейса или очисткой localStorage.

## Что считается уязвимостью

- XSS, небезопасная обработка пользовательских данных или уязвимость зависимостей.
- Случайная отправка ответов или результатов на внешний сервер.
- Ошибка, позволяющая странице прочитать localStorage другого происхождения.
- Утечка секретов, если серверная инфраструктура появится в будущем.

## Что НЕ считается уязвимостью

- Проблемы, зависящие от настроек конкретного браузера или расширений.
- Невозможность восстановить данные после очистки пользователем localStorage.
